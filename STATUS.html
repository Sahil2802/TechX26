Environment notes

Windows Application Control blocks launcher executables and some compiled files here. Run the app with the 3.12 venv: %USERPROFILE%\venvs\aquagrid312\Scripts\python.exe -m uvicorn aquagrid.web:app --port 8000, then open http://localhost:8000. Build the frontend once first with npm --prefix frontend install and npm --prefix frontend run build. Always use python -m, never the bare uvicorn command. Every change in the console needs the OPERATOR_TOKEN from .env. If the demo machine has a similar policy, WNTR may not load there, and the check will use its plain-Python fallback.
